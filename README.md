# Smart Calories Calculator

A robust Python program that calculates daily energy needs and builds tailored nutrition plans.

## Features
- **Accurate Calculations:** Computes BMR and TDEE using the Mifflin-St Jeor equation based on your personal metrics and activity level.
- **Goal Planning:** Supports maintaining, losing, or gaining weight. Enter your target weight and timeframe, and the app calculates the required daily caloric deficit/surplus.
- **Smart Safety Alerts:** Automatically evaluates your progress rate and warns against aggressive or unhealthy targets while suggesting safe, sustainable paces.
- **Macronutrient Breakdown:** Estimates daily intake for protein, carbs, and fats.
- **Input Validation:** Handles errors smoothly with a seamless loop for restarting or exiting.
